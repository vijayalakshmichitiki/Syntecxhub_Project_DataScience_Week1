# Sales Data Analysis – Syntecxhub Internship

## Project Description
This project analyzes sales data using time series and category-based visualizations.

## Tools Used
- Python
- Pandas
- Matplotlib

## Visualizations
- Monthly sales trend (Line chart)
- Sales by category (Bar chart)
- Category sales share (Pie chart)

## Conclusion
Electronics is the highest revenue-generating category, and overall sales show an increasing trend.
